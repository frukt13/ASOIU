# Домашнее задание №3 — вариант 26

Предметная область: **школы → ученики**. Числовой показатель: `avg_grade` — средний балл успеваемости.

## Стек

- C# и ASP.NET Core MVC (`net8.0`)
- SQLite
- Entity Framework Core Code First
- LINQ to Entities

## Что реализовано

- Модели `School` и `Student` со связью один-ко-многим.
- `AppDbContext` с двумя `DbSet<T>`.
- Автоматическое создание SQLite-базы через `EnsureCreated()`.
- Начальные данные: 4 школы и 12 учеников.
- CRUD для школ, включая запрет удаления школы со связанными учениками.
- CRUD для учеников, выпадающий список школ и валидация неотрицательного среднего балла.
- Отчёт из трёх разделов: полный список, количество учеников по школам, средний балл по школам по убыванию.
- Навигационное меню.
- LINQ и EF Core без прямых SQL-строк.
- XML-комментарии для публичных классов и их публичных членов.

## Быстрый запуск отдельно

Откройте файл `Homework3.Variant26.sln` в Visual Studio, назначьте проект запускаемым и нажмите `F5`.

## Как добавить проект в существующее решение AASOIU

1. Распакуйте папку проекта рядом с папками других работ, например в `homework3_variant26`.
2. В Visual Studio нажмите правой кнопкой по верхней строке `Решение "AASOIU"`.
3. Выберите `Добавить → Существующий проект...`.
4. Укажите файл `Homework3.Variant26.csproj`.
5. Нажмите правой кнопкой по проекту `Homework3.Variant26` и выберите `Назначить запускаемым проектом`.
6. Нажмите `F5` или `Ctrl + F5`.

При первом запуске в рабочей папке приложения автоматически создаётся файл базы данных `homework3_variant26.db`.

## Запуск через терминал

```bash
dotnet restore
dotnet run --project Homework3.Variant26.csproj
```

После запуска откройте адрес, показанный в терминале. По умолчанию профиль HTTP использует `http://localhost:5196`.

## SOLID, ООП и DRY — кратко

- ООП: модели `School` и `Student`, связь один-ко-многим, наследование `AppDbContext : DbContext`, переопределение `OnConfiguring` и `OnModelCreating`.
- SRP: модели, контекст БД, инициализатор, CRUD-контроллеры и отчёт разделены по ответственности.
- DRY: методы `BuildSchoolOptions` и `ValidateSchool` используются и при добавлении, и при редактировании ученика; общее меню хранится в `_Layout.cshtml`.
- DIP применён частично: SQLite скрыт за EF Core, но в учебной версии контекст создаётся через `using var context = new AppDbContext()` в соответствии с требованиями задания.
